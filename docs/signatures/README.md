## Installing

Outlook for Windows (classic): close Outlook, copy the person's `.html` into
`%APPDATA%\Microsoft\Signatures\`, reopen Outlook and choose it under
File > Options > Mail > Signatures. This route keeps the watermark. Pasting
from a browser into the signature editor drops background images.

New Outlook and Outlook on the web: open the `.html` in a browser, select all,
copy, paste into Settings > Mail > Compose and reply > Email signature.

Gmail: same copy and paste into Settings > General > Signature. Gmail
strips nothing that matters here.

Apple Mail: paste into Settings > Signatures, then untick "Always match my
default message font".

Mobile apps keep their own signature. Outlook for iOS and Android can be
set to use the account signature under Settings > Signature.

## Regenerating

```
python docs/signatures/build_signatures.py --png
```

`--png` needs Playwright with Chromium (`pip install playwright`,
`playwright install chromium`). Without it the HTML still builds.
